# 🛡️ PhishGuard - Phishing Awareness Simulator

A safe and interactive web-based phishing awareness simulator designed to help users recognize common phishing attacks and understand how to stay protected.

## 🎯 Project Objective

The purpose of this project is to provide cybersecurity awareness training through realistic but completely simulated phishing scenarios.

The simulator helps users:

- Identify common phishing warning signs
- Understand different phishing techniques
- Analyze suspicious emails
- Test their knowledge through a quiz
- Learn practical security tips
- Track their training progress

## 🚀 Features

### 📧 Phishing Email Simulation

Users can inspect a simulated suspicious email and identify potential red flags such as:

- Urgent requests
- Suspicious sender addresses
- Requests for verification
- Suspicious links

The simulator provides immediate feedback based on the user's selections.

### 🧠 Phishing Techniques

The project explains several common phishing techniques:

- Email Phishing
- Spear Phishing
- Smishing
- Vishing
- Clone Phishing
- Social Engineering

### 🛡️ Security Awareness Tips

Users learn practical methods to protect themselves, including:

- Checking links before clicking
- Verifying senders
- Protecting credentials
- Thinking before responding
- Using security tools
- Reporting suspicious messages

### 📝 Security Quiz

The simulator contains an interactive quiz covering common phishing scenarios and safe security practices.

### 📊 Progress Dashboard

The dashboard tracks:

- Quiz performance
- Email analysis completion
- Awareness level
- Overall training progress

## 🔐 Safety

This project is designed strictly for **cybersecurity education and awareness**.

It does **not**:

- Collect real passwords
- Collect real credentials
- Store sensitive personal information
- Send real phishing emails
- Attempt to impersonate real organizations

All phishing scenarios are simulated for educational purposes.
